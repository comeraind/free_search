# free_search.py —— 零依赖免费搜索命令行工具

## 这是什么

一句话：在命令行里输一句话，就能同时从 Bing、搜狗、360、百度、GitHub 这些免费搜索里拿到结果，不用来回开网站。

为什么要做它：平时查资料，经常要开好几个搜索网站来回切换，有的还想让你登录、充会员。这个工具把免费搜索源拼在一起，一条命令搞定，结果直接打印在屏幕上。

## 环境要求

- Python 3.9 以上（免费的，去 python.org 下载安装就行）
- **不需要装任何第三方库，不用 pip install 任何东西**，复制下来就能跑

## 三步跑起来

1. 下载本仓库里的 `free_search.py` 这一个文件（点开它，点右上角 Raw，右键另存为，或直接 Download）。
2. 在这个文件所在的文件夹里打开终端（Windows：在文件夹地址栏输 `cmd` 回车；Mac：在文件夹右键选「打开终端」）。
3. 输入：

```
python free_search.py "你想查的词"
```

运行完，屏幕上会打印一条条「标题 + 链接 + 摘要」，最后一行告诉你这次实际用了哪个搜索源。

## 常用参数

| 参数 | 例子 | 说明 |
| --- | --- | --- |
| （第一个） | `python free_search.py "Python 教程"` | 要查的话，用引号包住 |
| `--limit` | `--limit 5` | 返回几条结果，默认 8 条 |
| `--source` | `--source sogou` | 指定用哪个搜索源，默认 `auto`（自动降级：一个源失败了自动换下一个） |

可选的源：

- `auto` — 默认，按实测可用性自动选源并降级（顺序：bing → sogou → so360 → baidu → github）
- `bing` — 微软必应，中文英文都可以
- `sogou` — 搜狗，中文内容相关度常常更好（部分结果没有摘要，链接是搜狗站内跳转链接，点开还是原页面）
- `so360` — 360 搜索
- `baidu` — 百度（有时会撞上「百度安全验证」，脚本不会绕过，会自动换下一个源）
- `github` — GitHub 仓库搜索（免费但官方限速 10 次/分钟，别频繁用它）
- `searx` — SearXNG 公共实例。**已实测全部超时，不可用**，不进自动降级链，写在这里只是保留选项

## 已知局限（照实说）

- **长英文句子查询不好用。** 实测查 `Fantasy Premier League terms of use commercial`，Bing 会把这句话拆成一个一个单词再搜，结果里全是词典页（百度百科 FANTASY、fantasy 中文翻译、剑桥词典之类），完全不是想要的。**中文查询好用，短的英文词组基本可用，整句英文别指望。**
- 免费搜索源的页面随时可能改版：脚本靠解析写死的网页 HTML 结构，对方一改版按钮/排版，解析就可能失效。
- 可能撞上对方的验证码（比如百度）。脚本的原则是**不绕过**，撞上就换下一个源。
- 所以**不保证永远可用**。今天能用不代表明天还能用。
